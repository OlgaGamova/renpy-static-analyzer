# renpy-static-analyzer
Система статического анализа и верификации нелинейных интерактивных сценариев

## Установка

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

## Запуск

### Веб-интерфейс
Запустите сервер:
```
py -m uvicorn core.api:app --reload
```
Откройте в браузере: `http://127.0.0.1:8000/static/index.html`

### CLI-анализатор
Запустите анализ файла:
```
py -m cli.main <путь_к_файлу.rpy>
```
Или для демонстрации:
```
py -m cli.main
```
